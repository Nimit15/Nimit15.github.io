# OpenSolve AI Lab website

A lightweight static website for the OpenSolve AI Lab umbrella initiative. It links to the current public projects and describes them as they exist today, including their development stage and limitations.

## Publish with GitHub Pages

1. Upload `index.html` and `README.md` to the root of `Nimit15/Nimit15.github.io` on the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under build and deployment, choose **Deploy from a branch**, select `main`, and choose `/(root)`.
4. Save and wait for the Pages deployment to finish.
5. Open `https://nimit15.github.io` and check the site on desktop and mobile.

## Before applying to any startup programme

- Keep project status accurate; CYCLO-INTEL is described as a local prototype and its forecast replay is historical validation rather than a live forecast service.
- The driver-drowsiness repository is a team project; retain contributor acknowledgements.
- Check code, dataset, model-weight, and third-party asset licences before describing any project as open source or promising unrestricted reuse.
- The site intentionally contains no invented company registration, customers, revenue, funding, or employee claims.

## Local preview

Open `index.html` directly in a browser. There is no build step or external JavaScript dependency.
