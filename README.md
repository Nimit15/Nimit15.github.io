# OpenSolve AI Lab

**Useful AI for real problems. Built openly.**

OpenSolve AI Lab is an independent, founder-led project space maintained by Nimit Sharma. I use it to build and share practical AI and machine-learning projects, explore ideas through hands-on experiments, and make the code and lessons easier for other people to understand and try.

The projects are at different stages. I aim to document what each one does, how to run it, what the results show, and where its limitations are.

**Website:** https://nimit15.github.io  
**GitHub profile:** https://github.com/Nimit15

## Projects

### CYCLO-INTEL — Cyclone intelligence

An AI-assisted prototype for satellite-image analysis, cyclone-intensity estimation, Grad-CAM explanations, links to official alerts, and regional-language safety guidance.

- **Code and setup:** [Nimit15/SIH26070-Cyclone-AI](https://github.com/Nimit15/SIH26070-Cyclone-AI)
- **Current status:** Local application prototype.
- **Important limitation:** The forecast replay is a historical validation demonstration, not a live forecasting service. The project does not replace official IMD or disaster-management warnings.

### Driver Drowsiness Detection

A computer-vision project combining deep-learning models and facial-geometry signals to estimate signs of driver drowsiness and raise an alert.

- **Code and setup:** [Driver-Drowsiness-Detection-Using-Deep-Learning-Techniques](https://github.com/Nimit15/Driver-Drowsiness-Detection-Using-Deep-Learning-Techniques)
- **Current status:** Academic team project. See the repository for contributor acknowledgements, setup requirements, results, and implementation details.

## How I approach projects

- **Build for a real use case.** Start with a practical problem and work toward something people can try.
- **Explain the work.** Keep setup instructions, dependencies, and implementation choices understandable.
- **Show the evidence.** Report evaluation results without overstating what they mean.
- **Be clear about limitations.** Distinguish a prototype from a dependable, deployed service.
- **Respect the work of others.** Check code, dataset, model-weight, and third-party asset licences before reuse.
